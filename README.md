# SOC Log Analyzer

## Overview

SOC Log Analyzer is a Python-based security tool designed to analyze log files and generate simple security reports.

The tool detects:

- Failed Login Attempts
- Successful Logins
- Warnings
- Errors

It also calculates risk levels and provides security recommendations based on detected activities.

---

## Features

- Log File Analysis
- Failed Login Detection
- Warning and Error Detection
- Risk Level Assessment
- Security Recommendations
- Alert Generation
